# 공통 검사 10개 — AUD 추가

입력과 기대값은 A/B 동일하다. A는 기능 미완성 항목을 실패 또는 미실행으로 정직하게 기록한다. 판정 이유와 증거를 함께 남긴다.

| ID | 입력·행동 | 기대값 |
|---|---|---|
| AUD-01 | 실제 환율 화면 열기 | AUD 카드와 1 AUD당 원화 표시. A 인계 시 —·연결 준비 중, B 완료 시 정상값 또는 정직한 상태 안내 |
| AUD-02 | 정상 조회 실행 | 기존 5개 통화 유지, JPY는 100엔 기준 |
| AUD-03 | AUD 정상 응답 원자료·화면 대조 | base AUD, quote KRW, 유한한 양수 rate; 화면값은 표시 자릿수 반올림과 일치 |
| AUD-04 | 정상 조회 후 새로고침 | 서버 저장 AUD·원천 기준일·수신 시각 유지 |
| AUD-05 | 동일 KST 날짜 정상 조회 3회 | 해당 날짜 DB 행 1개, 마지막 정상값으로 갱신 |
| AUD-06 | AUD 없는 기존 과거 행 불러오기 | 기존 통화 유지, AUD 기록 없음; 과거 행 전체를 거부하지 않음 |
| AUD-07 | 격리된 합성 기록: 어제 AUD 900원, 오늘 910원 | 차이 +10원, 변화율 +1.11%, 실제 DB 변경 없음 |
| AUD-08 | 아래 손상값·실패 5종을 각각 실행하고 정상 복구 | 잘못된 응답 거부, 마지막 정상값·기록 유지, 실패별 안내, 복구 후 fresh/none |
| AUD-09 | 1366×768·1920×1080·375px 폭 확인 | 카드 겹침·페이지 가로 넘침 없음; 표 내부 스크롤 허용 |
| AUD-10 | Tab 조회·화면 전환, 콘솔·변경 파일 확인 | 키보드 작동, 콘솔 빨간 오류 0건, 비밀키 원문 없음 |

AUD-08 손상 입력: AUD rate 문자열, 0, 음수, 필수 rate 누락.
실패 5종: 시간 초과, 외부 원천 401/403, 429 호출 제한, 오프라인, 응답 형식 변경.
정상값이 없는 초기 상태의 실패에서는 값이 없는 상태로 안내한다. 합성 데이터는 별도 메모리에서 검사하고 실제 날짜 기록을 대신하지 않는다.
브라우저 합성 검사만으로 실제 서버 API나 DB 실패 대응을 확인했다고 주장하지 않는다. 실행 계층을 증거에 적는다.

기록 양식: ID / 세션 / 환경·실제 입력 / 통과·실패·미실행 / 증거 / 남은 조치.
