# 과제 5 — 환율정보판 AUD 추가 작업 계획

작성일: 2026-10-08 (KST)
상태: 계획 문서 작성. 정식 A 시작·종료 기록은 아직 미등록.

## 개선 기능
과제 4 환율정보판에 호주 달러 AUD 한 개를 추가한다. 1 AUD당 원화 조회·서버 저장·화면 표시·어제 대비 비교를 지원한다. 기존 USD/EUR/JPY/CNY/GBP 기능을 보존한다. JPY는 100엔 기준이다. AUD가 없는 과거 기록에는 값을 만들어 넣지 않는다.

## 시작 소스와 공통 자료
- 시작 소스: https://github.com/pyeon-pyeon/Portfolio/tree/2e465aa318728c2d792ae8b85da8a4902f36b638
- 프로젝트 경로: 과제/환율정보판
- 공통 검사: CHECKS.md의 AUD-01~AUD-10
- 공통 최초 요청: 아래 요청문
- B는 같은 기준 소스와 검사를 확인하고, 실제 작업은 A의 인계 커밋에서 이어간다.

## 공통 사용 상한
A와 B 각각 작업 시작부터 경과 시간 60분, 사용자 작업 요청 최대 10회.
최초 요청·추가 구현 요청·수정 요청을 각각 1회로 센다. AI 내부 도구 호출은 별도로 기록하며 이 요청 상한에 합산하지 않는다.
경과 시간에는 작업 시작 후 검사를 위해 기다린 시간도 포함한다. 도달하면 중단·저장한다. 무료 한도를 일부러 소진하지 않는다.
정식 시작 전에 이 조건과 검사 문서를 저장한 커밋을 기록한다. 시작 전 초안 작업은 정식 A 측정에서 제외하고 별도 사실로 공개한다.

## AI A가 할 일과 계획한 중단 지점
1. 시작 커밋과 기존 코드를 읽고 실제 시작 시각·요청 수를 기록한다.
2. index.html에 AUD 카드, aud-title/aud-rate/aud-change ID를 추가한다.
3. AUD 값은 —, 안내는 연결 준비 중으로 표시한다. 임시 환율은 넣지 않는다.
4. style.css의 데스크톱 카드 배치를 3열로 조정한다. 작은 화면 미디어 쿼리는 유지한다.
5. board.js·서버 API·DB는 수정하지 않는다. 실제 조회 가능 통화는 5개이므로 제목도 유지한다.
6. 소스 구조·JS 구문을 검사하고, 가능한 브라우저 검사를 수행한다. 미실행을 통과로 기록하지 않는다.
7. A-RESULTS.md와 HANDOFF.md를 갱신하고 코드·문서를 저장한다.
8. AUD 카드와 레이아웃까지만 구현한 상태에서 중단한다. 상한이 먼저 오면 즉시 중단한다.

## AI B의 범위
AUD API 조회, 서버 검증, DB 열 및 행 변환, 브라우저 표시, 일별 이력, 어제 대비 계산, 합성 응답을 연결한다. AUD 없는 기존 행은 유지하고 AUD 비교는 기록 없음으로 표시한다. 동일 검사 10개를 실행하고 완료 커밋과 실제 결과를 남긴다. DB 마이그레이션은 SQL 파일로 제공하고 적용 여부를 기록한다.

## 두 AI에게 전달할 공통 최초 요청
```text
과제 4 환율정보판에 호주 달러 AUD를 추가하세요.
1 AUD당 원화 조회·서버 저장·화면 표시·어제 대비 비교를 지원하고,
기존 5개 통화와 AUD가 없는 과거 기록을 보존하세요.
첨부된 AUD-01~AUD-10 검사와 기대값은 변경하지 마세요.
사용 상한은 세션당 60분, 사용자 작업 요청 최대 10회입니다.
검사 결과는 통과·실패·미실행으로 구분하고 증거를 기록하세요.
이전 세션의 인수인계가 있으면 저장소와 문서만으로 이어가세요.
비밀값이나 확인하지 않은 결과를 문서에 기록하지 마세요.
```
공통 요청에 추가하여 A에게는 위 A 중단 지점을, B에게는 인계 커밋과 HANDOFF.md를 제공한다. B에게 이전 대화 전문은 제공하지 않는다.
