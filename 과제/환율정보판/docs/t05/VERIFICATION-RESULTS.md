# AUD 추가 코드 — 구현 후 추가 검증 결과

## 검사 대상과 기록의 성격
대상 커밋: https://github.com/pyeon-pyeon/Portfolio/tree/4fc5ea9c405b89b10fdd1fca79253adc1f44a83c
검사일: 2026-10-08 KST. 자동 검사 최초 시작 11:26:20, 최종 완료 2026-10-08T02:28:07.455Z (UTC, KST는 +9시간).

이 문서는 B 구현 후 기존 대화의 AI가 실행한 추가 검증이다. 사전 고정 후 수행한 A 구현 기록이나 새로운 B 세션의 자체 기록이 아니다. A/B의 실제 시간·요청 수·이전 대화 제공 여부를 이 검사로 증명하지 않는다.

## 실행 환경과 방법
Node.js v24.19.0. 외부 API·DB 응답은 격리된 fetch 대체 함수로 제공했다. 실제 Supabase 접속·쓰기 없음. 환경변수에는 검사용 가짜 주소·키만 사용했다.
서버 모듈의 공개 함수 및 _testing 검증 함수를 직접 실행했다.
board.js는 VM에서 DOM 이벤트 초기화 부분을 제외하고 원본 계산·합성 transport·상태 함수를 노출해 실행했다. 앱 소스는 변경하지 않았다. 실제 DOM·렌더링·키보드 검사를 대신하지 않는다.

서버 9개와 board.js 로직 11개, 총 20개 보조 검사가 통과했다. 공통 검사 10개 전체 통과를 뜻하지 않는다.
JS 구문 검사: board.js, api/_lib/exchange.js 통과.
브라우저 검사는 Chromium 실행 파일 부재로 시작하지 못했고, 다운로드가 손상되어 설치도 실패했다. 이 환경 오류를 앱 결함으로 판정하지 않았다.

## 확인한 결과
- AUD 신규 기록은 양수·원자료 일치를 검증하고 aud_krw에 매핑한다.
- AUD 값이 없는 과거 행은 기존 통화와 함께 읽을 수 있다.
- AUD 문자열·0·음수·누락은 신규 응답에서 거부한다.
- 외부 401/403, 429, 오프라인, 형식 변경, 시간 초과를 기대 오류로 분류한다.
- 실패 시 이전 정상값·기록 유지, 복구 후 fresh/none을 실제 JS 상태 함수로 확인했다.
- AUD 900→910 비교는 +10원, 1.11%다.

## 남은 확인과 발견 사항
최신 커밋에 DB 마이그레이션 SQL 파일은 없다. 코드가 aud_krw를 조회하므로 실제 Supabase에 NULL 허용 양수 컬럼이 추가되어 있는지 사용자가 확인해야 한다. 컬럼 적용 여부는 이번 검사로 확인하지 못했다.
실제 배포 URL을 받지 않아 공개 화면·로그인 없이 접근·실제 환율·키보드·콘솔·해상도 검사는 하지 않았다.
A/B 자체 기록과 공개 비교 보고서는 별도로 완성해야 한다.
