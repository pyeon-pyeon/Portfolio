편승훈의 IT·보안 소개

이 페이지는 IT·보안 직무 채용 담당자에게 저의 경력, 담당 경험, 일하는 방식을 보여주는 개인 소개 페이지입니다.

경험으로 소개하는 강점 3가지

01. 주도성

상황
의료기기 소프트웨어의 구조부터 구현까지 직접 정해야 했습니다.
행동
아키텍처·DB를 설계하고 로그인, 결과 저장, PDF 생성과 배포를 구현했습니다.
결과
촬영부터 진단 결과 확인·PDF 출력까지 이어지는 소프트웨어를 구축했습니다.

02. 학습 민첩성

상황
Spring을 배웠지만 실무에는 처음 접하는 Rust·Svelte·Tauri가 필요했습니다.
행동
각 기술의 구조와 사용법을 배우고 백엔드·화면·데스크톱 앱에 적용했습니다.
결과
새로운 기술로 로그인과 진단 결과 기능을 구현하고 배포했습니다.

03. 문제 해결력

상황
서버에서 AI 추론을 수행할 때 동시 요청으로 응답이 지연됐습니다.
행동
추론 실행 위치를 서버에서 각 장치의 로컬 환경으로 전환했습니다.
결과
추론을 각 장치에서 수행하도록 바꾸어 서버에 집중되던 추론 부하를 줄였습니다.

문제 해결력의 근거 · 처리 구조 변경

기존에는 서버에서 처리하던 AI 추론을 각 장치의 로컬 환경에서 처리하도록 변경했습니다.

추론 구조 변경 과정 보기

변경 전: 서버가 AI 추론을 처리해 동시 요청 시 응답이 지연됐습니다.

변경 후: 각 장치에서 추론을 수행하도록 변경해 서버에 집중되던 추론 부하를 줄였습니다.

담당 경험에 따른 결과 설명이며, 내부 코드와 환자 자료는 공개하지 않습니다.

공개 범위 점검표

공개할 정보

  • 이름과 간단한 자기소개
  • 경력 요약과 직접 담당한 업무
  • 사용 기술과 공개 가능한 프로젝트 설명

공개하지 않을 정보

  • 전화번호와 상세 주소
  • 회사 내부 코드와 서버 접속 정보
  • 환자·고객 개인정보와 계정·비밀값
