    집계 기간 선택

    집계 기간: 전체

    집계 기준 확인
    • 계획 수: 선택 기간과 시작일~종료일이 겹치는 계획입니다.
    • 할 일 수: 마감일이 선택 기간에 포함되는 할 일입니다.
    • 완료 수: 위 할 일 중 현재 완료 상태인 항목입니다. 완료 시각 기준의 통계는 아닙니다.
    • 지연 수: 위 할 일 중 현재 KST 날짜보다 마감일이 이전이고, 완료·취소 상태가 아닌 항목입니다.
    • 막힘 수: 실행 날짜가 선택 기간에 포함되고, 막힌 이유가 적힌 실행 기록 수입니다.
    • 예상 시간: 마감일이 선택 기간에 포함된 할 일 중 취소하지 않은 항목의 예상 시간 합계입니다.
    • 실제 시간: 실행 날짜가 선택 기간에 포함되는 실행 기록의 실제 시간 합계입니다.
    • 완료율: 완료 수 ÷ 취소하지 않은 할 일 수 × 100입니다. 분모가 0이면 표시하지 않습니다.

    현재 저장된 상태로 집계합니다. 예상과 실제 시간은 날짜 귀속 기준이 다르므로 개별 계획의 비교표도 함께 확인하세요.

      01 · PLAN

      어떤 일을 할 계획인가요?

      새 계획

      실제로 하고 있는 일의 기간과 성공 기준을 정하세요. 수정 전 내용은 계획 이력으로 보존됩니다.

      계획 저장 전 · ID와 버전 없음

      계획 작성

      계획 전체 예상 시간과 할 일 예상 합계는 별도로 저장합니다.

      처음 계획과 수정 이력

      새 계획은 버전 1부터 보존됩니다. 기존 자료의 확장 시점 기준본은 최초 작성본과 구분합니다.

      계획에 담을 할 일

      먼저 계획을 저장하거나 왼쪽에서 선택하세요.

      할 일 작성

      쉼표로 구분하며 태그당 30자, 최대 10개입니다.

      할 일 찾기와 정렬

      정렬: 등록 순서. 같은 값이면 등록 시각, ID 순입니다.

      조회 전

      표시할 할 일이 없습니다.

        02 · DO

        실제로 무엇을 했나요?

        실행 기록은 계획과 별도로 저장됩니다. 나눠 수행한 일은 기록을 각각 추가하세요.

        실행 기록 작성

        시작·종료 시각을 입력하면 실제 시간이 계산됩니다.

        실제 시간은 분 단위로 올림합니다. 한 기록은 최대 24시간이며 실행 날짜는 시작 시각의 KST 날짜입니다.

        선택한 계획의 실행 기록

        아직 실행 기록이 없습니다.
