# 편승훈 · IT·보안 포트폴리오

IT 운영·보안 채용 담당자에게 의료기기 소프트웨어 구축 경험, 문제 해결 방식, 공격 시뮬레이션 제작 경험을 소개하는 한 페이지입니다.

## 실행 및 배포

빌드 도구나 환경 변수 없이 동작하는 정적 사이트입니다. `index.html`을 브라우저에서 열거나 `python -m http.server 8000`으로 실행합니다.

Vercel에서 이 저장소를 가져온 뒤 Framework Preset을 Other로 선택합니다. Build Command는 비우고 Output Directory는 루트(`.`)로 지정합니다. 배포 후 로그인 없이 시크릿 창에서 확인합니다.

## 공개 범위

이름, 경력 요약, 사용 기술, 담당 역할, GitHub 링크를 공개합니다. 회사 코드·운영 주소·환자 및 고객 정보·연락처·계정·비밀값은 포함하지 않습니다. 프로젝트 설명은 담당 업무를 설명하는 자료이며 회사 내부 소스나 실측 성능 자료를 공개하는 것은 아닙니다.

## 확인 방법 4줄

- 위치: 공개 페이지의 소개·경험·연결 영역. 기준 화면은 PC 1440×900, 모바일 390×844.
- 행동: 페이지 열기 → 경험 메뉴 선택 → 프로젝트의 상세 흐름 펼치기. 키보드는 Tab으로 이동하고 Enter로 실행합니다.
- 통과 모습: 해당 영역으로 이동하고 상세 설명이 펼쳐집니다. 두 화면에서 내용이 잘리지 않고 키보드 초점이 보입니다.
- 안 될 때 모습: 빈 화면, 가로 넘침, 메뉴 이동 실패, 상세 설명이 열리지 않음, 키보드 초점이 보이지 않음 중 하나가 나타납니다.

## AI와 내 판단 3줄 (제출 전 본인 확인)

- AI에게 맡긴 일: 소개 페이지의 구성·문구 초안, HTML·CSS 구현과 기본 확인.
- 직접 판단한 일: IT·보안 채용 담당자를 대상으로 선택하고 이름·경력·담당 역할 중심의 공개 범위를 정함.
- AI 제안을 따르지 않은 일: 현재 별도로 거절한 제안은 없음. 제안이 선택한 대상과 공개 범위에 부합했기 때문임. 제출 전에 실제 판단에 맞게 수정할 것.

## 제출 상태

공개 결과물 URL과 최종 full commit URL은 배포·커밋 후 기록합니다. 실제 브라우저 검사와 시크릿 창 공개 접근 확인은 완료한 결과만 기록해야 합니다.
