# Hash Lab

비밀번호 저장을 배우는 개발자가 salt의 역할과 후보 검증 비용의
차이를 이해하도록, salted SHA-256·bcrypt·Argon2id를
가상 데이터로 비교하는 앱입니다.

## 바탕 논문과 확장 범위

논문:
「Salt만으로 충분한가?
SHA-256과 bcrypt의 비밀번호 후보 검증 비용 비교」

작성자: 편승훈
작성일: 2026-10-14

논문에서 활용한 결과:
Salt에 따라 저장값이 달라져도 높은 후보 검증 비용이
자동으로 보장되지는 않습니다.

기존 논문은 Python 환경에서 salted SHA-256과 bcrypt를 비교했습니다.
앱은 브라우저 WebAssembly 환경에서 새로 측정하며,
Argon2id는 앱에서 추가한 확장 실험입니다.

## 사용자가 할 일 세 가지

1. Salt 효과 확인
   같은 가상 문자열에 다른 salt를 적용해 저장값을 비교합니다.

2. 세 방식 측정
   가상 후보 수와 비용 설정을 선택해 검증 시간을 비교합니다.

3. 논문과 대조
   기존 논문 수치와 현재 측정의 조건·차이·한계를 확인합니다.

## 실행 환경

- Python 3
- 최신 Chrome·Edge·Firefox·Safari 등
- Web Worker·WebAssembly 지원
- localhost 또는 HTTPS 환경

Python은 정적 파일 서버 실행에만 사용합니다.
추가 Python 패키지는 필요하지 않습니다.

HTML 파일을 직접 더블클릭하는 file 주소에서는
실습 실행을 지원하지 않습니다.

## 실행 방법 3단계

### 1. 압축 풀기

새 임시 폴더에 ZIP을 풉니다.
위 파일 구성과 vendor 파일 두 개를 확인합니다.

### 2. 서버 실행

index.html이 있는 폴더에서 실행합니다.

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

### 3. 앱 열기

브라우저에서 아래 주소를 엽니다.

```text
http://localhost:8000
```

준비 완료 후 다음 순서로 사용합니다.

- 서로 다른 Salt로 계산
- 세 방식 비교 실행
- 논문 결과와 대조하기

서버 종료는 터미널에서 Ctrl+C를 누릅니다.

8000 포트를 사용 중이면 다른 포트로 실행합니다.

```powershell
python -m http.server 8001 --bind 127.0.0.1
```

이때 접속 주소는 http://localhost:8001입니다.

## 측정 방법

- 실제 계정이나 유출된 해시를 사용하지 않습니다.
- 가상 후보 목록은 앱 내부에서 생성합니다.
- 모든 방식이 같은 후보 목록을 사용합니다.
- 정답을 찾아도 후보 목록 끝까지 검사합니다.
- 목표 해시 생성과 준비 실행은 검증 시간에서 제외합니다.
- SHA-256은 약 250ms를 목표로 전체 목록을 반복합니다.
- SHA-256은 최대 100만 검증으로 제한합니다.
- bcrypt와 Argon2id는 후보 목록을 한 번씩 검증합니다.
- 후보당 시간은 총 검증 시간을 실제 검증 횟수로 나눕니다.
- 초당 검증 수는 검증 횟수를 검증 시간으로 나눕니다.
- 시간은 performance.now로 측정합니다.
- 순서는 SHA-256 → bcrypt → Argon2id로 고정합니다.

SHA-256은 반복 구간의 전체 경과 시간을 사용합니다.
bcrypt와 Argon2id는 각 검증 호출의 경과 시간을 합산하며,
진행 알림은 해당 측정 구간 밖에서 처리합니다.

SHA-256의 목록 반복은 독립적인 반복 실험 횟수가 아닙니다.
이 앱은 연구 논문의 통계 실험을 그대로 재현하는 도구가 아니라
계산 비용의 차이를 체험하는 도구입니다.

## 측정 설정

### bcrypt

- cost 10 또는 12

### Argon2id

- 메모리 19·32·64 MiB
- 반복 2 또는 3
- 병렬도 1
- 출력 길이 32바이트

메모리는 알고리즘의 설정값입니다.
브라우저 전체 메모리 사용량을 측정하지 않습니다.

알고리즘별 cost·반복·메모리 수치가 같거나 비슷하다고
동일한 보안 수준을 의미하지 않습니다.

## 취소와 오류 처리

측정 중 취소하면 Worker를 종료하여 계산을 중단합니다.
미완료 결과는 완료 결과로 저장하지 않습니다.
새 Worker를 준비한 뒤 다시 실행할 수 있습니다.

허용되지 않은 후보 수나 비용 설정은 거부합니다.
중복 실행은 제한합니다.

Worker에는 90초 제한 검사가 있으며,
화면에서는 응답이 120초를 넘으면 Worker를 종료합니다.
모듈 초기 준비 제한은 15초입니다.

오류가 나면 화면 안내를 확인합니다.
모듈 오류 이후에는 페이지를 새로고침해 다시 준비합니다.

## 개인정보와 외부 전송

실제 비밀번호를 입력하는 칸은 없습니다.
제공된 가상 문자열과 생성된 가상 후보만 사용합니다.

실습 입력과 결과를 서버로 전송하지 않습니다.
서버는 HTML·CSS·JavaScript·논문 파일을 제공하는 용도입니다.
정적 파일 요청 자체는 발생합니다.

결과는 사용자가 JSON 저장을 선택할 때 파일로 내려받습니다.
앱은 쿠키·localStorage·DB에 실습 결과를 저장하지 않습니다.

외부 AI API를 호출하지 않으므로 API 키나 환경변수가 필요하지 않습니다.
외부 참고문헌 링크는 사용자가 선택할 때 해당 사이트로 이동합니다.
